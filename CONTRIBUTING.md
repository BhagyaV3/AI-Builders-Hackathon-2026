# Contributing to AccessBridge

Thank you for contributing to AccessBridge.

## Overview

AccessBridge is a hackathon project focused on turning complex forms into an accessible, guided, and verifiable experience. Contributions should support that goal and stay aligned with the current MVP scope.

## Description

This repository is being built in a short hackathon window, so contributions should be small, focused, and easy to review. The main source of truth for planned work is [github-issues.md](./github-issues.md).

## Running the Application Locally

The full application is not built yet, so there is no local run process at the moment.

When implementation starts, contributors should follow the setup instructions that will be added to the repo and keep the app runnable in the local dev environment.

## Contributions

### Identify a Change

Pick a concrete task, bug, or small feature slice from [github-issues.md](./github-issues.md).

### Descriptive Titles

Use short, specific titles that make it obvious what the change does.

### Branch Creation

- Create a branch for each task.
- Use a branch name tied to the work, for example: `backend-form-extraction` or `frontend-guided-flow`.
- Keep branches focused on one issue when possible.

### Code

- Keep changes focused, readable, and easy to review.
- Prefer clear code over clever code.
- Preserve accessibility behavior and source fidelity.
- Do not remove deadlines, conditions, or warnings during simplification.

### Pull Request

- Keep pull requests small and reviewable.
- Include a short summary of what changed.
- Mention any issue numbers the PR closes or supports.
- Add screenshots or notes if the change affects the UI.

### Review

- Ask questions early if a task is blocked.
- Leave comments on issues or PRs when assumptions change.
- Coordinate handoffs between backend, AI, frontend, and QA work.

### Merging

- Merge only when the change is stable and still matches the project scope.
- Optional and stretch ideas should stay optional unless the core flow is already stable.
